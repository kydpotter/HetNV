# HetNV: Heteroskedastic Normalized Vecchia Gaussian Processes 


This repository contains code accompanying the manuscript:

> **Scalable Heteroskedastic Gaussian Process Models for Large Inhomogeneous Datasets**

The repository will include:

- Simulation scripts for the 1D and 2D heteroskedastic experiments
- Code used for the APS case study
- Functions implementing the HetNV methodology
- Scripts used to generate manuscript figures and tables
- An R package implementation of HetNV (in development)

## Data Availability

The datasets and processed analysis files used in this work are currently undergoing institutional review and approval for public release. Once approval is complete, all releasable data associated with the manuscript will be added to this repository.

Until release approval is finalized, the repository may contain:
- simulation-generation scripts,
- analysis pipelines,
- figure-generation code,
- and documentation sufficient to reproduce the computational workflow structure.

## Reproducibility

All simulation settings and primary modeling choices are described in the manuscript. The repository will be updated alongside publication to provide fully reproducible analysis scripts and supporting documentation.
